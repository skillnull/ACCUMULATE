# 文字环绕与混合字体对齐

适用：中文、数字、符号与图标居中，以及段落标签和来源自然换行。先复用已有组件；浏览器、iOS、Android 共用实现。顺序固定为：统一内部高度 → flex 居中 → 校正原字体字形 → 全状态交叉验证。

## 名称、数字与图标：先同高再居中

- 父行使用明确高度和 `align-items: center`；名称、数值、前缀的**实际文字容器也必须同高**。只给父行 flex、子项仍用各自自然行高，不是最终方案。主行和辅助行分别使用各自设计高度，不强行统一字号。
- 名称和数值容器用 flex/inline-flex，内部 `align-items: center`、`justify-content: center`，高度继承明确的父行高度。名称保留 `min-width: 0`，数值和按钮禁止收缩；行内间距用 margin。
- 图标显式声明 CSS 宽高、`display: block`、`flex-shrink: 0`，与文字采用同一 px/rem 缩放体系。SVG 数字宽高属性不会随 px-to-rem 自动缩放。
- 日期胶囊同样先固定内部高度，再居中文字和箭头；独立核对文字与箭头间距。图标框可以采用设计尺寸，但须与同一行共享中心线。
- 不按系统或正负值分别移动整行；字体族、字重、字形保持指定值。字体缺失或回退须核实，不能换字体掩盖错位。

```scss
.value-row {
  display: flex;
  align-items: center;
  height: 24px; // 按当前组件的设计高度设置。

  &__name,
  &__value {
    display: inline-flex;
    align-items: center;
    justify-content: center;
    height: 100%;
    line-height: normal;
  }

  &__name { min-width: 0; }
  &__value { flex-shrink: 0; margin-left: 2px; }
}
```

## 原字体字形校正

同高 flex 解决布局；仍有字面偏差时，才在文字组件内校正原字体。不要重新叠加父层偏移。

- 核对实际选用字体及每个字重的字形度量。`document.fonts.check()` 成功或 CSS 字体名相同，不能单独证明没有回退。用 `(yMin + yMax) / 2 / unitsPerEm` 得到对应字形的归一化中心。
- 已有实现采用原字体的单个 SVG `text`，以 `y="50%"` 定位；同文 DOM 负责固有宽度和可访问文本，SVG 设为 `aria-hidden`，逐字保持原文。不得改成图片、绘制替代符号或修改字体文件。
- 数字统一采用同一个数字基线，无符号正数、负数、零必须一致。单个 `text` 的 `dy` 列表：无符号首字符取数字中心；带符号首字符取符号中心，第二字符取“数字中心 − 符号中心”，其余取 0。字重、占位符及不同符号分别使用已核对的度量，不套用通用负号偏移量。
- 中文、日期与原文中的符号按实际字体匹配已验证度量；未知字体保留常规文本排版。字体加载完成后刷新，度量可按字体族、字重和样式缓存；不为每个数据项反复探测。
- 修复同一问题时使用单一定位机制。整串数字基线和符号内部校正分开核对，不把某一条负数的截图当作正数、零和小字号也正确的证据。

## 段落与标签

- 正文用普通行内 span；标签、来源用 inline-flex。三者统一 vertical-align: middle，标签和来源内部双轴居中。不把整段改成 flex/grid 或正文独占一列。
- 段落保留设计行高；标签固定高度，内部文字及正文可用 line-height: normal，以目标字体实测为准。不用 line-height: 1 加偏移反复补偿。
- 不同字号受父级字形行盒影响时，可在保留行高的前提下将父级字号置零，所有子文字必须显式保留设计字号；先用实际段落验证。
- 标签内容使用接口完整原文，原有竖线等符号也属于原文；不另造分隔线或改写内容来对齐。
- 来源文字、数量与箭头保持同组；续行回到段落左边缘。文字、加号、数量、箭头各自的字面中心都需验证。
- 同组只保留最终定位机制，移除被替代的 top、margin-top、translateY 等补偿，不叠加新旧方案。
- 区分标签 padding 与外部 margin。左右留白分别测量，扣除边框，考虑 min-width 和字形侧边距；不凭遮罩添加不对称 padding。

## 已排除的方向

- 用替代字体、修改字体文件或字体别名换取对齐。
- 只改 line-height、只让父行 flex 居中、反复试 top/translateY，或为 iOS/Android 堆两套偏移。
- 把负号拆成独立文本片段并继续叠加补偿；假定父 `text` 与首个 `tspan` 的 dy 会按预期累加。
- 将 `text-rendering: geometricPrecision` 当作修复：本次浏览器与移动端实验未提供有效改善，已撤回。
- 将未验证的 Canvas 加号度量实验作为最终方案；该实验已撤回。

## 整体验证与适用边界

- 先验证浏览器，再验证 iOS 真机，并交叉核对 Android。复用已打开页面；目标必须是当前前台页面，刷新后确认最新代码和字体已生效。
- 一次覆盖主行与辅助行、无符号正数、负数、零、百分号、不同字号、短名/长名、展开/收起；有换行、占位符或显式正号时，也要验证对应状态。日期、标签、来源及箭头按受影响范围一起检查。
- 同时检查子项同高、内部居中、实际笔画、间距与裁切。DOMRect、理论字体中心或一个负数样例均不能单独作为验收证据；用户仍反馈异常时不得宣布通过。
- 用当前页面的有效截图核对真实字形。错误重复的长截图、后台页面截图不能作证；JPEG 不用于精细像素结论，物理像素与 CSS 像素必须区分。字体抗锯齿产生的亚像素差不能直接等同于未居中或绝对居中。
- 本次最终方案已在浏览器、iOS 真机和 Android 模拟器交叉核对；这不代表所有系统版本或 Android 真机均已实测。辅助来源文案的 `+` 在 iOS 仍有用户接受暂缓的轻微偏差，不将这一点记为已解决，也不将其校正值推广到其他字体。
- 长名称的缩字号与省略另见 [自适应字号文本组件](auto-fit-text-component.md)。居中通过不代表省略通过；自定义 slot/SVG 在最小字号下的硬裁切不能记为正常省略。
