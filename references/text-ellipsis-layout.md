# 跨端文本省略与动态排版

用于落实 [文本省略与兼容](../rules/text-ellipsis.md) 的原生能力选择、动态布局和必要回退。共享输入、排版约束与验收目标；不绑定编程语言、框架或单份组件源码。

## 按渲染能力适配

| 目标环境 | 优先方式 | 适配边界 |
| --- | --- | --- |
| Web / H5 / WebView | CSS 原生单行或多行省略 | CSS、DOM 和浏览器观察器仅在对应引擎中适用 |
| 原生移动端或桌面控件 | 平台文本控件、段落与文本布局引擎 | 使用本端字体度量、缩放与生命周期，不依赖浏览器对象 |
| 跨平台 UI 框架 | 该框架实际渲染器提供的文本能力 | 核对最终落到 Web、原生控件还是自绘引擎，不能按框架名称猜测等效行为 |
| 小程序等受限运行时 | 平台文本组件及允许的布局查询 | 先核对编译产物和能力限制，不预设可访问 DOM |
| 自绘、图形或文档渲染 | 对应引擎的字体排版、行布局与裁切 | 文字与省略号在同一排版坐标和字体体系下测量、绘制 |
| 无排版上下文的服务端 | 保留完整原文，明确字符数限制的独立契约 | 缺少字体、尺寸与排版器时不能保证视觉行数 |

先查目标项目现有封装和运行时官方能力，再选择实现。各端分别核对行数限制、尾部省略和所需对齐能否组合；不能满足时如实记录缺口，不静默放宽验收条件。

## 动态排版协议

1. 确认完整原文、最大行数、换行策略、对齐要求、文本方向、实际字体及尺寸约束。字符数量不等同于渲染宽度。
2. 在本端布局完成后读取有效尺寸和实际行盒；不可见或尺寸为零时等待可见性/布局事件。先撤销本实现上一次的临时校正，避免旧字号、旧宽度或旧省略状态影响新判断。
3. 优先让原生排版器决定断行。必须自定义尾部时，用实际省略号尺寸预留区域，让正文避让；正文、尾部和裁切范围使用同一坐标、缩放和字体度量。
4. 统一行高的纯文本可使用“行数 × 实际行高”作为高度上限；富文本、混合字号或不同基线以各行实际布局为准。字体放大而行高未同步时，校正需容纳实际文字范围，不能沿用固定像素上限。
5. 只按原始有效布局判断是否溢出，不能让尾部占位本身制造溢出。内容、参数变化后保留临时覆盖的归属信息，保证放大再缩小、替换内容后仍可还原。
6. 通过本端的数据、字体/缩放、容器、样式、资源加载和显隐事件刷新。按帧或布局批次合并任务，过滤自身写入，销毁时释放观察器、监听和待执行任务；不用持续轮询兜底未知变化。
7. 原生能力不足时才选择本端最小回退；遵守用户对脚本、测量和自定义省略号的限制。需要字符串裁剪时按字素及排版结果处理，不按字节或固定字符个数猜测像素宽度。

## 条件案例：Web 浮动占位

仅适用于支持 CSS 浮动绕排的 Web 渲染器：原生方案已在目标环境复现问题，且允许独立省略号与少量布局测量。它不是纯 CSS 或浏览器原生自动省略，不是其他端必须采用的组件结构。

- 保留完整纯文本。DOM 顺序为零宽侧向浮动占位、同侧浮动尾部、原文；按文本方向和需求选择侧向。左到右文本、右侧尾部时，尾部用 `clear: right` 落到末行。
- 统一行高时，占位高度为（行数 − 1）× 实际行高，尾部为一行高，容器隐藏后续行。不要叠加原生 `line-clamp` 或绝对定位遮罩。
- 字体探针只感知字体布局变化，放在容器滚动区域之外，避免空文本误判。实际行高可结合计算样式与原文文本节点的 `Range` 行内矩形；不逐字测宽、不复制全文做二分搜索。
- 先取消尾部占位，再比较 `scrollHeight > clientHeight`。容器、占位和尾部高度同步更新；对齐及内部字体须承受页面字号样式变化，必要优先级只限制在组件内部。
- 观察容器与字体探针的尺寸，兼顾祖先属性、样式注入/加载、字体和可见性事件；不能只监听宽度。浏览器 API 做特性检测，保留本端回退并过滤自身写入。
- 内部探针、占位和省略号对无障碍隐藏，保留完整可访问原文。连续英文长串可能缺少可分配的对齐间隙；不保证任意内容逐行满铺。
- 旧环境中不可观察的样式表 CSSOM 等变化，需接入宿主布局事件或显式刷新；不得宣称监听所有外部操作。

## 条件案例：非 Web 渲染器

- 采用本端文本控件或排版引擎提供的行布局、裁切和尾部省略，绑定本端数据及布局生命周期。
- 原生控件不能组合所需对齐与省略时，再评估本端行盒测量、尾部预留或受控绘制。不能把 CSS 浮动、DOM 节点或浏览器观察器作为实现前提。
- 按实际字体回退、系统文字缩放和布局方向复核边界；完整原文与辅助功能沿用该平台的语义方式。

通用验收只维护在规则页。每种适配记录实际验证的运行时和最低版本；一个 Web 案例或静态检查通过，不推广为其他端、语言或框架已经兼容。
