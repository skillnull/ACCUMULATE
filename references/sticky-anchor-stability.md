# 吸顶锚点稳定性

适用：渐变 Header、普通/吸顶锚点切换、滚动选中和点击定位。

## 实现

1. 统一状态栏、固定 Header、锚点高度。吸顶 top 和点击偏移复用同一几何基准；实测亚像素白缝可覆盖 1px，不叠加魔法数。
2. 普通层始终占位，固定层独立显示，共享选中状态和点击函数。切换不增删占位高度，不让定位模式改变触发边界。
3. 滚动监听 passive，以 requestAnimationFrame 合帧；不做时间防抖。提前缓存区块绝对坐标，滚动热路径只读 scrollTop，不反复测量状态相关 DOM。
4. 进入阈值用 boundary + enterOffset，退出用 boundary − exitOffset。边界取自产品指定元素原始坐标，避免临界反复切换。
5. 切换优先只变 opacity；禁止缩放、布局属性动画和 transition: all。隐藏层同步关闭 pointer-events、键盘焦点与可访问性暴露。
6. 定位值 = 区块顶部 − Header 高度 − 吸顶锚点高度，并夹在 0 与最大滚动距离之间。点击立即选中，定位后用同一坐标校准；到页底明确选中末项，向上跨区可加小幅滞回。
7. 数据、图片、字体、展开、图表显隐或窗口变化后，在 DOM/资源更新完成时重测坐标和最大滚距。
8. 按产品恢复滚动。若要求刷新回顶部，设置 history.scrollRestoration = "manual"，初始化及 pageshow 归零，卸载恢复原值并清理监听/动画帧。

状态分开保存吸顶、选中、原始边界、区块坐标、上次滚距和帧 ID；Header 渐变不混入选中状态。

## 验收

- 慢速跨界及边界往返不闪烁、缩放、跳位；Header 无缝且无内容穿透。
- 逐项及快速连续点击定位正确，标题不被遮挡；末项到页底仍选中。
- 内容尺寸变化后定位准确；刷新、前进后退、pageshow 符合恢复要求。
- 用移动端真机或等效视口检查亚像素和滚动边界，不能只看静态截图。
