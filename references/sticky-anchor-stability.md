# 吸顶锚点稳定性

用于实现或修复以下组合交互：页面头部渐变、普通锚点切换为吸顶锚点、滚动同步选中、点击锚点定位，以及 Header 与锚点的无缝衔接。

## 核心约束

1. **先确定唯一几何基准**
   - 明确状态栏、固定 Header、吸顶锚点各自的高度。
   - 吸顶锚点的 `top` 必须直接由固定 Header 的底边计算，点击定位偏移也必须复用同一组高度。
   - 若移动端出现亚像素白缝，可让吸顶锚点向上覆盖 Header `1px`；不要用无来源的多组魔法数分别补偿。

2. **普通态与吸顶态保持结构稳定**
   - 优先保留普通锚点在文档流中占位，再使用独立的固定锚点层覆盖显示。
   - 切换状态时不得增删占位高度，也不得让同一节点在 `relative`、`fixed` 间切换后反向影响触发边界。
   - 两层必须复用同一个选中状态和同一个点击处理函数，但样式可以独立还原设计稿。

3. **滚动热路径使用 `requestAnimationFrame` 合帧**
   - 滚动监听使用 `{ passive: true }`，每帧最多计算一次。
   - 不用时间防抖处理视觉状态；防抖会造成状态滞后和跳变。
   - 不在滚动回调中反复读取会随吸顶状态变化的 `getBoundingClientRect()`。进入页面、内容尺寸变化或窗口变化后缓存绝对位置，滚动时只读取 `scrollTop` 并比较数值。

4. **吸顶切换必须有滞回区间**
   - 进入吸顶与退出吸顶不能共用同一个像素阈值。
   - 进入条件使用 `boundary + enterOffset`，退出条件使用 `boundary - exitOffset`，避免临界点因取整、亚像素和布局变化反复切换。
   - 触发语义以产品要求为准。例如“日期标题行到达 Header 下边缘时吸顶”，应从该标题行原始绝对位置计算边界，不能凭视觉猜测替换元素。

5. **动画只改变不参与布局的属性**
   - 普通态与吸顶态切换优先使用 `opacity`。
   - 禁止对锚点容器做缩放动画，也不要过渡 `top`、`height`、`margin`、`padding` 或 `transform: scale(...)`。
   - 禁止 `transition: all`。透明层必须同步控制 `pointer-events`、`tabindex` 和 `aria-hidden`，避免不可见层截获点击或焦点。

6. **点击定位和滚动选中必须共用坐标体系**
   - 目标位置统一为“目标区块绝对顶部减去固定 Header 与吸顶锚点总高度”。
   - 定位值应夹在 `0` 与最大可滚动距离之间。
   - 点击后立即设置点击项为选中项，再执行定位；定位完成后用同一套滚动计算校准。
   - 页面底部无法把最后一个区块推到吸顶线时，必须显式识别“已到页面底部”，并选中最后一个锚点，不能误选前一项。
   - 向上滚动可为选中边界增加小幅滞回，避免相邻模块边界来回闪烁。

7. **内容尺寸变化后重新测量**
   - 接口数据切换、图片加载、折叠展开、字体变化、图表显隐和窗口尺寸变化，都会使锚点位置失效。
   - 在 DOM 更新后的 `nextTick` 或对应资源完成事件中重新缓存锚点位置与最大滚动距离。
   - 不要依赖浏览器自动恢复旧滚动位置。产品要求刷新回顶部时，设置 `history.scrollRestoration = "manual"`，并在初始化及 `pageshow` 时显式归零，卸载时恢复原值。

## 推荐状态模型

- `isStuck`：只表示普通层与固定层的显示状态。
- `activeAnchorId`：只表示当前选中的锚点。
- `anchorOriginTop`：普通锚点原始绝对顶部。
- `anchorPositions`：各内容区块的绝对顶部缓存。
- `previousScrollTop`：判断滚动方向，用于选中态滞回。
- `scrollFrameId`：保证滚动处理每帧最多执行一次。

不要把 Header 渐变进度、吸顶状态和锚点选中状态合成一个含义不清的状态变量。

## 验收清单

- 从顶部慢速跨越吸顶边界，普通层与固定层只切换一次。
- 在边界上下小幅往返滚动，不闪烁、不缩放、不跳位。
- Header 与固定锚点之间没有可见缝隙，也没有内容穿透。
- 点击每个锚点后，目标标题不被固定区域遮挡。
- 点击最后一个锚点且页面已到最底部时，仍保持最后一项选中。
- 快速连续点击锚点后，选中态与最终位置一致。
- 图片加载、模块展开或图表显隐后，定位仍准确。
- 刷新、前进后退和 `pageshow` 场景符合产品的滚动恢复要求。
- 在移动端真机或等效视口验证亚像素缝隙与滚动临界点，不能只看桌面浏览器静态截图。
