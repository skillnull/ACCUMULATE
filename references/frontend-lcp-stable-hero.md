# 前端 LCP 稳定首屏优化

适用：主视觉晚出现、远程图加载慢、框架/路由启动阻塞首屏。

## 不变量

- 先记录接口、鉴权、Bridge、订阅、图标、交互、埋点和错误/重试时序。保持原自动加载契约；不靠点击、展开或进入视口延后关键依赖换取指标。
- 保留接口、Mock、loading、超时、权限和异常处理；监控/RUM/埋点的导入、初始化、用户设置和首事件顺序默认不变。调整观测加载须用户明确批准并证明数据不丢失。
- 优化留在业务路由/组件/资源模块。禁止向共享 index.html 新增业务判断、脚本、模板、图片、样式，或通过构建配置间接注入；历史存量仅经明确授权处理。
- 不用透明元素、无关骨架、大文本或瞬时占位伪造 LCP；静态首屏提前不等于整页可用。

## 诊断

同条件记录视口、网络/CPU、缓存、登录态、参数和业务分支；测试信息须脱敏。

| 证据 | 优先处理 |
| --- | --- |
| LCP 资源请求发起晚 | 发现时机、连接、优先级、格式和尺寸 |
| 资源早到但节点晚出现 | 框架、异步路由、开发懒编译、v-if、接口门控和节点替换 |
| LCP 与 TBT 同时高 | 启动链、重依赖解析执行和长任务 |

用 Performance/Lighthouse 明细或 PerformanceObserver 确认真实 LCP 节点、currentSrc、尺寸、请求/绘制时间与长任务。最大背景可能不算 LCP，不能凭视觉推断。

## 业务模块内首屏

1. 轻量同步路由壳持续持有最终主视觉及固定布局，重业务组件立即异步加载；不把完整页同步塞进所有路由主包。
2. 无需接口的导航、静态文案和布局立即出现。动态区域按产品要求显示骨架/占位，不猜业务标题或状态；加载期不能只剩背景。预留尺寸，复用正式卡片框架。
3. 原接口、鉴权、Bridge、订阅、弹窗和复杂内容仍随页面自动启动。拆分后逐项核对加载、错误、刷新及交互契约。
4. 主视觉不等接口，不从占位节点替换成另一正式节点；标题/动态覆盖层不重复创建，首个操作保持可用。

## 图片与资源发现

- 在业务路由精确命中时提前 preconnect CDN，并 preload 最终图片；必要时补 dns-prefetch，首图 eager/fetchpriority=high。站内进入由路由生命周期处理。
- preload 与最终 currentSrc 完全一致，包括格式、尺寸、质量和参数；只抢占一个会选中的格式，按规范化绝对 URL 去重。
- 原生 picture/source 提供 WebP，img 保留 PNG/JPEG 回退、明确 width/height 或宽高比、decoding=async。装饰图 alt 为空，有意义的图提供替代文本。
- 可远程替换的图保留稳定 CDN 地址，不拷进包或 Base64。复用图片组件前查 eager、优先级和属性透传；若延迟创建节点或不能透传，首图用原生 picture/img。
- Hash 不发送给服务端；客户端匹配覆盖合法查询串且避免前缀误命中。需解析期发现时可评估服务端 Link preload/103 Early Hints，但必须有服务端可见路径、域名或显式参数；不得给共享入口无差别下发业务图。
- 业务清单留在业务目录；共享工具无业务判断、扫描和自动副作用。单页不引入全局注册器；多页确需共用时须隔离清单异常、去重并回归，未命中路由零专属 DOM/请求且启动语义不变。

## 启动链与资源竞争

- 只拆不参与首屏 DOM/样式、鉴权、观测或首次决策的依赖。重指令可同步注册轻代理，挂载即加载实现，Promise 去重并转发生命周期；先卸载不得迟到挂载或订阅。
- 实时数据能力拆包仍须挂载即加载并订阅。只在操作时需要的辅助函数可随操作加载，关键按钮、图标及首个可用状态不属于此类。
- 共享拆包核对自动请求、仅一次初始化、可见异常及清理；回归使用与未使用该能力的路由。不为单页预加载给所有路由增加异步启动跳数或同步扫描。
- 立即异步不减少总下载量；结合瀑布检查 chunk 是否与首图争带宽。只对产品原本允许延后的图片/请求用 lazy、合理 rootMargin、裁剪、质量控制和低优先级。
- 长图按展示宽度取远程尺寸，避免重复处理参数；收紧预取距离后检查快速滚动空白。隐藏 DOM 仍可能请求资源。
- 开发 lazy compilation/HMR 噪声单独标注；可在性能验收配置预编译入口并保留异步模块编译，不把开发编译改善当生产收益。
- 独立入口仅在服务端可区分、共享启动链确为主瓶颈、复用鉴权/观测/Bridge 契约且可承担发布回归成本时考虑；不为提前一张图片拆多入口。
- 模块内仍未达预算，报告实际瓶颈与架构限制，继续优化启动成本。

## 验收

- 相同条件至少 3 次冷启动，报告中位数，必要时补最差/P90；记录 FCP、LCP、TBT/INP、CLS、应用可用时间和订阅启动时间。
- 核对 LCP 节点、资源瀑布、图片仅一次请求、优先级及 currentSrc/preload 一致；区分下载、编译、执行与绘制。
- 无需操作即有关键请求/订阅；首屏图标和按钮可用，权限、loading、失败/重试、Mock、Bridge、埋点、返回刷新、布局和滚动正常。
- 回归根路由、目标路由及已有重点路由；未命中无专属资源，共享能力快速挂载/卸载无泄漏或迟到初始化。
- 检查控制台/Network、未使用 preload、共享入口/模板无本次业务注入，并执行受影响文件检查。已有开发服务直接验证；需要生产结论时用获准的生产或等价环境数据。
